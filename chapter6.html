Chapter 6: Web Technology I

Grade 11 Computer Science

Introduction

Web technology refers to the collection of technologies, tools, and techniques used to create, publish, and access websites and web applications through the Internet. Today, the World Wide Web has become an important part of education, business, communication, entertainment, and many other fields.

A website can contain text, images, audio, video, hyperlinks, forms, animations, and other interactive elements. Web developers use different technologies such as HTML, CSS, JavaScript, web browsers, web servers, and content management systems to create and manage websites.

6.1 Introduction to Web Development

Web development is the process of creating and maintaining websites and web applications that are accessed through the Internet or a local network.

Web development includes designing web pages, writing code, organizing content, testing websites, and publishing them on a web server.

Types of Web Development

  1. Front-end Development
  2. Back-end Development
  3. Full-stack Development

Front-end Development

Front-end development deals with the visible part of a website that users see and interact with.

Main technologies used:

  • HTML
  • CSS
  • JavaScript

Back-end Development

Back-end development deals with the server-side part of a website. It manages databases, user accounts, processing, and communication between the server and the client.

Full-stack Development

Full-stack development includes both front-end and back-end development.

Basic Web Development Process

  1. Planning the website
  2. Designing the layout
  3. Creating web pages
  4. Adding content
  5. Testing the website
  6. Publishing the website
  7. Maintaining and updating the website

6.2 Web Browsers and Search Engines

Web Browser

A web browser is application software used to access, view, and interact with websites and web pages on the Internet.

A web browser receives web pages from web servers and displays them in a user-friendly format.

Examples of Web Browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Main Features of a Web Browser

  • Displays web pages
  • Supports hyperlinks
  • Provides navigation buttons
  • Stores browsing history
  • Supports bookmarks
  • Allows downloading files
  • Supports multimedia content
  • Provides security features

Search Engine

A search engine is a web-based software system that helps users find information on the Internet by entering keywords or search queries.

Examples of Search Engines

  • Google
  • Bing
  • Yahoo
  • DuckDuckGo
  • Baidu

How a Search Engine Works

  1. Crawling web pages
  2. Indexing information
  3. Processing search queries
  4. Displaying relevant results

Web Browser Search Engine

Installed on a device Accessed through a browser
Chrome, Firefox, Edge Google, Bing, Yahoo

6.4 HTML: The Language of the Web

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages.

HTML uses different tags to define elements such as headings, paragraphs, images, links, tables, lists, forms, audio, and video.

HTML is called a markup language because it uses tags to describe the structure and content of a web page.

6.4.1 Objectives of HTML

  • To create web pages
  • To structure web content
  • To display text and multimedia
  • To create hyperlinks
  • To organize information using lists and tables
  • To collect information using forms
  • To connect different web pages

6.4.2 Structure of HTML

A basic HTML document contains the HTML, HEAD, TITLE, and BODY tags. 

<!DOCTYPE html>
<html>

<head>
    <title>My Web Page</title>
</head>

<body>
    <h1>Welcome to My Website</h1>
    <p>This is a simple web page.</p>
</body>

</html>

Explanation

  • <html> defines an HTML document.
  • <head> contains information about the document.
  • <title> defines the title shown in the browser tab.
  • <body> contains the visible content of the web page.

6.4.3 Publishing and Hosting

Publishing a website means making a website available for users on the Internet.

Web hosting is a service that provides space on a web server where website files can be stored and accessed through the Internet.

Steps for Publishing a Website

  1. Create web pages using HTML.
  2. Save the website files.
  3. Register a domain name.
  4. Choose a web hosting service.
  5. Upload website files to the server.
  6. Test the website.
  7. Make the website available to users.

6.4.4 HTML Tags and Attributes

HTML Tag

An HTML tag is a keyword enclosed within angle brackets that defines an element in an HTML document. 

<p>This is a paragraph.</p>

Most HTML tags have an opening tag and a closing tag.

HTML Attribute

An attribute provides additional information about an HTML element. 

<p align="center">Hello</p>

Difference Between Tags and Attributes

HTML Tag HTML Attribute
Defines an HTML element Provides additional information

6.5 Cascading Style Sheets

6.5.1 Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance and presentation of HTML elements.

CSS can be used to change colors, fonts, spacing, borders, layouts, backgrounds, and other visual properties of a web page.

Advantages of CSS

  • Separates content from design
  • Improves website appearance
  • Reduces repeated formatting code
  • Makes websites easier to maintain
  • Allows consistent design across multiple pages

Basic CSS Syntax

selector
{
    property: value;
}

Example:

p
{
    color: blue;
}

6.5.2 Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. 

<p style="color: red;">
This is red text.
</p>

Advantages

  • Easy for small changes
  • Directly affects a single element

Disadvantages

  • Not suitable for large websites
  • Mixes HTML content with design
  • Difficult to maintain

6.5.3 Embedded CSS

Embedded CSS is written inside the STYLE tag within the HEAD section of an HTML document. 

<html>

<head>

<style>

p
{
    color: blue;
}

</style>

</head>

<body>

<p>Hello World</p>

</body>

</html>

Advantages

  • Useful for a single web page
  • Provides better organization than inline CSS
  • Can style multiple elements

Disadvantages

  • Cannot easily be reused across many pages
  • Can make the HTML document longer

6.5.4 External CSS

External CSS is written in a separate file with the .css extension. The CSS file is connected to an HTML document using the LINK tag.

HTML File

<head>
    <link rel="stylesheet" href="style.css">
</head>

CSS File: style.css

p
{
    color: green;
}

h1
{
    color: blue;
}

Advantages

  • Can be used by multiple web pages
  • Easy to maintain
  • Keeps HTML and CSS separate
  • Provides consistent design

Disadvantages

  • Requires an additional file
  • The web page may depend on the CSS file being available

Comparison of Types of CSS

Type Location Use
Inline CSS Inside an HTML element Single element
Embedded CSS Inside STYLE tag Single HTML page
External CSS Separate CSS file Multiple HTML pages
