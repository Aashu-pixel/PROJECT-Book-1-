Chapter 3: Software and Operating System

3.1 Concept of Software

A computer system consists of two major components: hardware and software. Hardware refers to the physical components of a computer that can be seen and touched, such as the keyboard, monitor, CPU, and mouse. Software refers to the collection of programs and instructions that tell the computer hardware what to do.

Without software, computer hardware cannot perform useful tasks. Similarly, software requires hardware to run. Therefore, hardware and software are closely related and work together to make a computer system functional.

3.1.1 Definition of Software

Software is a collection of programs, procedures, and related data that instructs a computer to perform specific tasks.

A program is a set of instructions written in a programming language. These instructions are executed by the computer to solve problems or perform particular activities.

Examples of Software

  • Microsoft Word is used for creating documents.
  • Google Chrome is used for browsing the internet.
  • Photoshop is used for editing images.
  • Windows is used to manage computer hardware and software resources.

Software cannot be physically touched because it is an intangible component of a computer system.

Characteristics of Software

  1. Software is intangible and cannot be physically touched.
  2. It consists of programs and instructions.
  3. It controls and manages computer hardware.
  4. It is developed using programming languages.
  5. It can be copied, modified, and updated.
  6. It helps users perform different tasks using a computer.

3.1.2 Categories of Software

Software can be categorized according to its purpose and functionality. The major categories of software are:

  1. System Software
  2. Utility Software
  3. Application Software
  4. Web-Based Software
  5. Mobile Applications

A. System Software

System software is a type of software designed to manage and control computer hardware. It provides a platform on which application software can run.

System software acts as an interface between the user, application programs, and computer hardware.

Examples of system software:

  • Operating systems
  • Device drivers
  • Language translators
  • System utilities

Examples of operating systems are Windows, Linux, macOS, and Android.

B. Utility Software

Utility software is designed to help maintain, analyze, protect, and optimize a computer system. It performs specific tasks related to the management of computer resources.

Examples of utility software:

  • Antivirus software
  • Disk cleanup tools
  • Backup software
  • File compression software
  • Disk defragmentation tools

For example, antivirus software protects a computer from viruses and other malicious programs.

C. Application Software

Application software is designed to help users perform specific tasks. It is developed according to the requirements of users.

  • Microsoft Word for word processing
  • Microsoft Excel for calculations
  • PowerPoint for presentations
  • Photoshop for image editing
  • VLC Media Player for playing multimedia files

Application software can be further classified into general-purpose software and customized software.

General-purpose software is designed for common tasks and can be used by many users.

Customized software is developed for a particular organization or user according to specific requirements.

D. Web-Based Software

Web-based software is software that runs through a web browser. It generally requires an internet connection and does not always need to be installed on the user's computer.

Examples:

  • Google Docs
  • Gmail
  • Online banking systems
  • Facebook
  • Google Classroom

Web-based applications allow users to access services and information from different locations using the internet.

E. Mobile Applications

Mobile applications, commonly called mobile apps, are software applications designed to run on smartphones, tablets, and other mobile devices.

Mobile applications are usually installed through application stores.

  • WhatsApp
  • Instagram
  • Google Maps
  • YouTube
  • Mobile banking applications

Mobile apps are designed to provide services conveniently through portable devices.

3.2 Concept of Operating System

An operating system is one of the most important types of system software. It manages the overall activities of a computer system and provides an environment for users and application programs.

Without an operating system, it would be difficult for users to communicate directly with computer hardware.

3.2.1 Introduction to Operating System

An Operating System (OS) is system software that manages computer hardware and software resources. It acts as an interface between the user and the computer hardware.

When a computer is turned on, the operating system is loaded into the main memory. It controls different operations of the computer and manages various hardware devices.

Common Operating Systems:

3.2.2 Role of Operating System

The operating system plays an important role in the proper functioning of a computer system.

1. Interface Between User and Computer

The operating system provides an interface through which users can communicate with the computer.

2. Resource Management

A computer has various resources which are managed by the operating system.

  • CPU
  • Memory
  • Storage devices
  • Input devices
  • Output devices

3. Program Execution

The operating system loads programs into memory and manages their execution.

4. File Management

The operating system helps users create, store, organize, copy, move, and delete files and folders.

5. Security Management

The operating system provides security mechanisms such as passwords and user accounts to protect data and resources.

3.2.3 Functions of an Operating System

1. Process Management

A process is a program that is currently being executed. The operating system manages different processes and decides which process should receive CPU time.

2. Memory Management

The operating system manages the main memory of a computer. It allocates memory to programs and releases memory when it is no longer required.

3. File Management

The operating system manages files and folders stored on storage devices.

  • Create files
  • Open files
  • Copy files
  • Move files
  • Rename files
  • Delete files

4. Device Management

A computer uses different devices, and the operating system manages communication between these devices and the computer.

  • Keyboard
  • Mouse
  • Printer
  • Monitor
  • Scanner

5. Security Management

The operating system protects the computer system from unauthorized access.

  • Password protection
  • User accounts
  • File permissions
  • Firewall
  • Encryption

6. User Interface

The operating system provides a user interface for interacting with the computer.

  • Command Line Interface (CLI)
  • Graphical User Interface (GUI)

7. Error Detection

The operating system detects errors that occur in hardware or software and takes appropriate action.

3.2.4 Operating System Terminology

A. Multiprogramming

Multiprogramming is an operating system technique in which multiple programs are stored in memory at the same time.

The CPU switches between programs when one program is waiting for an input or output operation. This technique helps increase CPU utilization.

Example: While one program waits for data from a disk, the CPU can execute another program.

B. Multitasking

Multitasking is the ability of an operating system to execute multiple tasks apparently at the same time.

The CPU rapidly switches between different tasks, giving the impression that all programs are running simultaneously.

Example: A user can listen to music while writing a document and downloading a file.

C. Multiprocessing

Multiprocessing refers to the use of two or more processors in a computer system. Multiple processors can execute different processes simultaneously.

Advantages of multiprocessing:

  • Faster processing
  • Better performance
  • Increased reliability
  • Ability to handle multiple tasks

D. Distributed Operating System

A distributed operating system manages a group of independent computers and makes them work together as a single system.

The computers communicate through a network and share resources.

Advantages:

  • Resource sharing
  • Improved performance
  • Increased reliability
  • Better communication

3.3 Windows Operating System

Windows is a popular operating system. It is widely used in personal computers and provides a graphical environment that makes computers easy to operate.

Windows uses graphical elements such as icons, menus, buttons, and windows.

3.3.1 Introduction to GUI Based Operating System and Its Features

A Graphical User Interface (GUI) is a type of interface that allows users to interact with a computer using graphical elements instead of typing only commands.

Common graphical elements:

  • Windows
  • Icons
  • Menus
  • Pointer
  • Buttons

This is commonly known as the WIMP interface.

Features of GUI-Based Operating Systems

  1. User-Friendly: GUI makes computers easier to use, especially for beginners.
  2. Uses Icons: Programs, files, and folders are represented using graphical symbols.
  3. Supports Mouse Operations: Users can interact using clicking, dragging, and dropping.
  4. Supports Multiple Windows: Users can open and work with multiple applications at the same time.
  5. Provides Visual Feedback: The system provides visual information about different activities.

3.3.2 Working in Desktop Application and Window Environment

The desktop is the main screen displayed after the operating system starts.

Major Components of Desktop

  1. Icons: Small graphical representations of programs, files, and folders.
  2. Taskbar: Contains shortcuts to programs and shows running applications.
  3. Start Menu: Provides access to programs, settings, and system features.
  4. Notification Area: Displays date, time, network status, battery status, and volume control.

Components of an Application Window

  • Title bar
  • Menu bar
  • Toolbar
  • Scroll bar
  • Status bar
  • Minimize button
  • Maximize button
  • Close button

Minimize: Temporarily hides a window from the desktop.

Maximize: Enlarges a window to fill the screen.

Close: Terminates the current window.

3.3.3 Manage Files and Folders with File Explorer

File Explorer is a file management application available in Windows. It allows users to organize and manage files and folders.

A file is a collection of related information stored under a specific name.

A folder is a container used to organize files and other folders.

Common File Operations

Operation Description
Creating Creating a new file or folder.
Copying Creates a duplicate of a file or folder.
Moving Transfers a file or folder to another location.
Renaming Changes the name of a file or folder.
Deleting Removes a file or folder from its original location.

Deleted files are generally moved to the Recycle Bin and can be restored if required.

3.3.4 Customize the Start Screen and Desktop

Windows allows users to customize the appearance and arrangement of the desktop.

Users can customize:

  • Desktop background
  • Themes
  • Screen resolution
  • Icons
  • Taskbar
  • Start Menu

Customization allows users to personalize their computer environment according to their preferences.

3.3.5 Installing and Removing Devices

Computers can be connected to different hardware devices.

  • Printers
  • Scanners
  • USB devices
  • Keyboards
  • Mice
  • Webcams

When a new device is connected, the operating system may automatically detect and install the required driver.

A device driver is software that allows the operating system to communicate with a specific hardware device.

3.3.6 Manage Passwords and Privacy Levels

Passwords help protect computer systems and personal information from unauthorized access.

A strong password should:

  • Contain uppercase and lowercase letters
  • Include numbers
  • Include special characters
  • Be difficult to guess
  • Not be shared with others

Privacy Settings

Privacy settings control how applications access personal information.

Users can control access to:

  • Location
  • Camera
  • Microphone
  • Contacts
  • Personal files

Proper privacy management helps protect personal data and improves computer security.

3.3.7 Use of Control Panel, System Tools and Accessories

Control Panel

The Control Panel is a Windows component used to manage and configure system settings.

  • Adding or removing programs
  • Managing devices
  • Changing display settings
  • Managing user accounts
  • Configuring network settings
  • Managing security settings

System Tools

System tools help users maintain and manage the computer system.

  1. Disk Cleanup: Removes unnecessary temporary files from storage.
  2. Disk Defragmenter: Reorganizes fragmented data on a hard disk.
  3. Backup and Restore: Helps users create backup copies of important data.
  4. Task Manager: Displays currently running programs and processes.

Accessories

Windows includes several basic applications called accessories.

  • Notepad
  • WordPad
  • Calculator
  • Paint
  • Snipping Tool

3.4 Open Source and Mobile Operating System

Operating systems can also be classified based on their source code and the type of devices on which they operate.

Open-source operating systems allow users to access and modify their source code. Mobile operating systems are specially designed for smartphones and other portable devices.

3.4.1 Concept of Open Source Operating System

An open-source operating system is an operating system whose source code is publicly available.

Users and developers can:

  • View the source code
  • Modify the source code
  • Improve the software
  • Distribute modified versions

Open-source software encourages collaboration among developers.

Examples:

  • Linux
  • Ubuntu
  • Fedora
  • Debian

Advantages of Open Source Operating Systems

  1. Usually available free of cost.
  2. Source code can be modified.
  3. Encourages collaboration.
  4. Provides flexibility.
  5. Can be customized according to user requirements.

Disadvantages

  1. May require technical knowledge.
  2. Some applications may not be compatible.
  3. Professional support may be limited in some cases.

3.4.2 Introduction to Linux and UNIX

UNIX

UNIX is a powerful multiuser and multitasking operating system.

Characteristics of UNIX:

  • Multiuser capability
  • Multitasking
  • Security
  • Portability
  • Stability

Linux

Linux is an open-source operating system based on UNIX principles.

Linux was initially developed by Linus Torvalds.

Linux is widely used in:

  • Personal computers
  • Servers
  • Supercomputers
  • Embedded systems

Linux is popular because it is stable, secure, and customizable.

Difference Between Linux and UNIX

3.4.3 Linux Distributions

A Linux distribution, commonly called a Linux distro, is a complete operating system built using the Linux kernel along with system software and applications.

Different Linux distributions are designed for different purposes.

Linux Distribution Description
Ubuntu User-friendly and popular among beginners.
Debian Known for stability and reliability.
Fedora Provides modern technologies and is widely used by developers.
Linux Mint Designed to provide a simple and user-friendly desktop environment.
Red Hat Enterprise Linux Designed mainly for business and enterprise environments.

3.4.4 Concept of Mobile Operating System

A mobile operating system is an operating system designed specifically for mobile devices such as smartphones and tablets.

It manages the hardware and software resources of mobile devices and provides an environment for running mobile applications.

Mobile operating systems manage:

  • Touchscreen input
  • Mobile applications
  • Wireless communication
  • Camera
  • Battery
  • Storage
  • Sensors

Mobile operating systems are designed to be efficient because mobile devices have limited battery power and smaller hardware resources compared to traditional computers.

3.4.5 Types of Mobile Operating System

1. Android

Android is a widely used mobile operating system. It is used by many smartphone manufacturers and supports a large number of mobile applications.

Features:

  • Touchscreen interface
  • Multitasking
  • Application support
  • Notification system
  • Customization

2. iOS

iOS is a mobile operating system developed for Apple's mobile devices.

Features:

  • Security
  • Performance
  • User-friendly interface
  • Integration with Apple devices

3. Windows Phone

Windows Phone was a mobile operating system developed for smartphones. It used a tile-based graphical interface.

Although it is no longer widely used, it is historically important in the development of mobile operating systems.

4. Symbian

Symbian was one of the early popular mobile operating systems.

It was widely used in older smartphones before Android and iOS became dominant.

5. BlackBerry OS

BlackBerry OS was developed primarily for BlackBerry smartphones.

It was known for its security features and business-oriented services.
