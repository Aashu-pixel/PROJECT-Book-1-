Chapter 5: Programming Concepts & Logics

Introduction

Programming is one of the most important areas of computer science. A computer can perform different tasks only when it is given proper instructions. These instructions are written in a programming language in the form of a program.

A programmer must understand programming concepts, problem-solving techniques, program design tools, and programming languages to develop a correct and efficient program.

This chapter introduces programming languages, translators, programming errors, control structures, algorithms, flowcharts, pseudocode, number and character representation systems, and the basic concepts of the C programming language.

5.1 Programming Concept

Programming is the process of designing, writing, testing, debugging, and maintaining a set of instructions that tells a computer how to perform a particular task.

A set of instructions written in a programming language to solve a problem is called a computer program.

The person who writes computer programs is called a programmer.

General Process of Programming

  1. Understanding the problem
  2. Designing a solution
  3. Preparing an algorithm
  4. Drawing a flowchart or writing pseudocode
  5. Writing the program
  6. Compiling or interpreting the program
  7. Testing the program
  8. Debugging errors
  9. Maintaining the program

5.1.1 Introduction to Programming Languages

A programming language is a formal language used to write instructions that can be understood and executed by a computer.

Computers understand machine language, which consists mainly of binary digits 0 and 1. However, writing programs directly in binary is difficult for humans. Therefore, different programming languages have been developed to make programming easier.

Examples of Programming Languages

  • C
  • C++
  • Java
  • Python
  • BASIC
  • JavaScript

Uses of Programming Languages

  • Develop computer software
  • Create websites
  • Develop mobile applications
  • Create games
  • Develop operating systems
  • Perform scientific calculations
  • Control machines and devices
  • Process and manage data

5.1.2 Low-Level, High-Level and 4GL Programming Languages

Low-Level Language

A low-level language is a programming language that is close to computer hardware.

Low-level languages are difficult for humans to understand but can be executed efficiently by computers.

The main types of low-level languages are:

  1. Machine Language
  2. Assembly Language

Machine Language

Machine language consists of binary digits, mainly 0 and 1. 

10110000 01100001

Advantages

  • Directly understood by the computer
  • Executes very quickly
  • Does not require a translator

Disadvantages

  • Difficult to write and understand
  • Difficult to debug
  • Machine dependent
  • Difficult to modify

Assembly Language

Assembly language uses mnemonic codes instead of binary instructions.

Examples of mnemonics:

  • ADD
  • SUB
  • MOV
  • MUL

An assembler is required to convert an assembly language program into machine language.

Advantages

  • Easier than machine language
  • Faster execution
  • Provides direct hardware control

Disadvantages

  • Machine dependent
  • Difficult compared to high-level languages
  • Requires knowledge of computer architecture

High-Level Language

A high-level language is a programming language that uses English-like words and mathematical symbols.

High-level languages are easier for humans to learn, write, and understand.

Examples

  • C
  • C++
  • Java
  • Python
  • BASIC

Advantages

  • Easy to learn
  • Easy to write
  • Easy to debug
  • Machine independent
  • Easier to maintain

Disadvantages

  • Requires a translator
  • May execute slower than machine language
  • Provides less direct hardware control

Fourth Generation Language (4GL)

A Fourth Generation Language (4GL) is a high-level programming language designed to make programming easier and faster.

4GLs generally require fewer instructions to perform a task.

Uses of 4GL

  • Database applications
  • Report generation
  • Data analysis
  • Business applications

Examples

  • SQL
  • MATLAB
  • SAS

Comparison of Programming Languages

Language Type Level Translator Example
Machine Language Very Low Not Required Binary Code
Assembly Language Low Assembler ADD, MOV
High-Level Language High Compiler/Interpreter C, Java
4GL Very High Special Translator SQL

5.1.3 Compiler, Interpreter and Assembler

A computer understands only machine language. Therefore, programs written in other languages must be translated into machine code.

Software used for this translation is called a language translator.

The main types are:

  1. Compiler
  2. Interpreter
  3. Assembler

Compiler

A compiler is a language translator that translates the entire source program into machine code at once.

After successful compilation, an executable program can be created.

Examples of Compiled Languages

  • C
  • C++
  • Pascal

Advantages

  • Execution is generally faster after compilation.
  • Errors can be displayed after compilation.
  • The compiled program can be executed multiple times.

Interpreter

An interpreter translates and executes a program one statement at a time.

Examples

  • Python
  • JavaScript

Advantages

  • Easier to test programs step by step.
  • Errors are reported one at a time.
  • No separate executable file is usually required.

Disadvantages

  • Execution is generally slower.
  • The program must be interpreted every time it is executed.

Assembler

An assembler is a translator used to convert assembly language into machine language. 

ADD A, B

Difference Between Compiler and Interpreter

Compiler Interpreter
Translates the whole program at once Translates one statement at a time
Execution is generally faster Execution is generally slower
Errors are displayed after compilation Errors are displayed line by line
Creates object or executable code Usually does not create a separate executable file
Used by languages such as C Used by languages such as Python

5.1.4 Syntax, Semantic and Runtime Errors

An error is a mistake in a program that causes incorrect results or prevents the program from executing properly.

  1. Syntax Error
  2. Semantic Error
  3. Runtime Error

Syntax Error

A syntax error occurs when the rules or grammar of a programming language are violated.

Example:

printf("Hello")

The above statement is missing a semicolon.

Correct form:

printf("Hello");

Semantic Error

A semantic error occurs when the syntax of a program is correct but the meaning or logic of the statement is incorrect. 

area = length + breadth;

Correct formula:

area = length * breadth;

Runtime Error

A runtime error occurs while a program is running.

Examples:

  • Division by zero
  • Accessing invalid memory
  • Opening a file that does not exist
result = 10 / 0;

5.1.5 Control Structures

The structure that controls the order of execution of statements is called a control structure.

  1. Sequence
  2. Selection
  3. Iteration

Sequence

In a sequence structure, statements are executed one after another in the order in which they are written. 

Input A
Input B
Sum = A + B
Display Sum

Selection

A selection structure is used when a program must choose between two or more alternatives based on a condition. 

If marks >= 40
    Display "Pass"
Else
    Display "Fail"

Iteration

An iteration structure is used to repeat a group of statements until a condition becomes false or for a specified number of times.

Examples of loops:

  • while
  • do-while
  • for

5.1.6 Program Design Tools

Before writing a program, the programmer should plan the solution to the problem.

Tools used to design and represent the solution of a problem are called program design tools.

  1. Algorithm
  2. Flowchart
  3. Pseudocode

Algorithm

An algorithm is a finite sequence of clear and logical steps used to solve a problem.

Characteristics of a Good Algorithm

  1. Input
  2. Output
  3. Definiteness
  4. Finiteness
  5. Effectiveness

Example: Algorithm to Find the Sum of Two Numbers

  1. Start
  2. Input two numbers A and B
  3. Calculate Sum = A + B
  4. Display Sum
  5. Stop

Flowchart

A flowchart is a graphical representation of an algorithm. It uses different symbols to represent different operations.

Symbol Type Purpose
Oval Start or Stop
Rectangle Processing
Parallelogram Input or Output
Diamond Decision
Arrow Direction of flow

Advantages of Flowchart

  • Easy to understand
  • Provides a visual representation
  • Helps in program development
  • Makes debugging easier
  • Helps identify logical errors

Pseudocode

Pseudocode is an informal way of writing the steps of a program using simple English-like statements. 

START
INPUT A, B
SUM = A + B
PRINT SUM
STOP

5.2 C Programming Language

C is one of the most important and widely used programming languages. It is a general-purpose programming language used for developing different types of software and system applications.

5.2.1 Introduction and Features of C Language

The C programming language was developed by Dennis Ritchie at Bell Laboratories in the early 1970s.

C is called a general-purpose and structured programming language.

Uses of C Language

  • System programming
  • Application development
  • Operating systems
  • Embedded systems
  • Scientific programs

Features of C Language

  1. Simple and efficient
  2. Structured programming language
  3. Portable
  4. Fast execution
  5. Rich set of operators
  6. Supports functions
  7. Supports pointers
  8. Supports dynamic memory allocation
  9. Suitable for system programming

Advantages of C

  • Easy to learn
  • Efficient and fast
  • Portable
  • Supports modular programming
  • Provides low-level memory access

Limitations of C

  • Does not provide automatic garbage collection
  • Complex programs can be difficult to manage
  • Does not provide strong built-in object-oriented features

5.2.2 Structure of a C Program

A simple C program generally contains different sections such as preprocessor directives, functions, and program statements.

Example of a Simple C Program

#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}

Explanation

  • #include <stdio.h> includes the standard input/output header file.
  • int main() is the main function where program execution begins.
  • { } are braces used to define a block.
  • printf() displays output.
  • return 0; indicates successful completion of the program.

5.2.13 Selection Control Statements

Selection control statements are used to make decisions based on conditions.

  1. if
  2. if-else
  3. if-else-if
  4. Nested if
  5. switch

if Statement

if(condition)
{
    statements;
}

if-else Statement

if(condition)
{
    statements;
}
else
{
    statements;
}

if-else-if Ladder

if(marks >= 80)
    printf("Distinction");
else if(marks >= 60)
    printf("First Division");
else if(marks >= 40)
    printf("Second Division");
else
    printf("Fail");

Nested if

if(age >= 18)
{
    if(age <= 60)
    {
        printf("Eligible");
    }
}

switch Statement

{
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    default:
        statements;
}
