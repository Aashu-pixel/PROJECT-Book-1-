1.1 Introduction to Computer

A computer is an electronic programmable device that accepts data, processes it according to instructions, produces useful information and stores data or results for later use. The essential idea is the transformation of input into meaningful output.

A computer system can therefore be represented as:

Input → Processing → Output

Storage supports the whole cycle by retaining programs, input data, intermediate data and results.

Data and Information

Data consists of raw facts, figures, symbols or observations. Information is data that has been processed and organized so that it becomes meaningful to a user.

Concept

Example

78, 85, 91

Processing

Calculate total and average

1.2 Characteristics of Computers

Speed

A computer performs operations extremely quickly. Processing speed is commonly discussed in terms of cycles per second and other performance measures.

Accuracy

A computer can produce highly accurate results when the data, program and hardware are correct. Wrong input or faulty instructions can still produce wrong output.

Storage

Digital systems can store large quantities of information and retrieve it rapidly.

Diligence

A computer does not become tired or bored while repeatedly performing the same operation.

Automation

After a program and required input are supplied, many tasks can run with limited human intervention.

Versatility

The same general-purpose computer can be used for education, communication, business, design, entertainment and scientific work.

Reliability

Computers can perform repetitive operations consistently when their hardware and software are functioning correctly.

Multitasking

Modern operating systems can keep multiple applications or tasks active and share processor resources among them.



1.3 Applications of Computers

Education: e-learning, digital libraries, presentations, simulations, online assessment and virtual classrooms.

Business: accounting, inventory, payroll, customer management, communication and data analysis.

Banking and finance: electronic transactions, ATMs, online banking, record keeping and fraud monitoring.

Healthcare: patient records, medical imaging, laboratory systems, scheduling and hospital administration.

Government: digital records, online services, tax systems, identity services and e-governance.

Science and engineering: modelling, simulation, data analysis, computer-aided design and research.

Communication: email, instant messaging, video conferencing and social platforms.

Entertainment: games, music, movies, animation and digital publishing.

1.7 Mobile Computing

Mobile computing means performing computing activities using portable devices and wireless communication. Smartphones, tablets and laptops allow users to access applications and information while moving between locations.

Applications include mobile banking, navigation, online learning, e-commerce, messaging, photography and remote work.

Mobile computing depends on a combination of portable hardware, operating systems, applications, wireless networks and security mechanisms.


1.8 Computer Architecture and Organization

Computer architecture describes the functional design and programmer-visible organization of a computer. Computer organization concerns how those functions are physically implemented through processors, memory, buses and input/output hardware.

Input Unit → CPU ↔ Memory/Storage → Output Unit

Major Components

Input unit: receives data and instructions.

Processing unit: performs calculations, comparisons and control operations.

Memory unit: holds instructions and data needed during processing.

Storage: retains information for longer-term use.

Output unit: presents processed information to users.


1.9 Microprocessor

A microprocessor is an integrated circuit that contains the main processing functions of a CPU. It executes instructions, performs arithmetic and logical operations, and controls the flow of data.

Clock speed

The number of clock cycles per second, commonly expressed in GHz. Clock frequency alone does not determine overall performance.

Word length

The number of bits a processor can naturally handle in a single operation or register width in a particular architecture.

ALU

Performs arithmetic and logical operations.

Control Unit

Coordinates instruction execution and signals among processor components.

Registers

Very fast small storage locations used during processing.


1.10 Bus System

A bus is a communication pathway that carries information among computer components.

Bus

Main purpose

Data bus

Carries data between processor, memory and other components.

Address bus

Carries addresses that identify memory or I/O locations.

Control bus

Carries signals that coordinate operations, such as read/write control.


1.11 Primary Memory

Primary memory is directly accessible by the processor and is used to hold instructions and data needed for current processing.

Memory

Characteristics

RAM

Read/write, generally volatile; stores currently active programs and data.

ROM

Non-volatile memory used for firmware or instructions that normally persist without power.

Cache

Very fast memory used to keep frequently needed data/instructions close to the processor.

Buffer

Temporary holding area used to smooth differences in data-transfer rates between devices or processes.

Types of RAM and ROM

Common RAM categories include SRAM and DRAM. SRAM is faster and more expensive per bit and is commonly used for cache; DRAM is denser and commonly used for main memory. ROM-family technologies include PROM, EPROM and EEPROM, representing different ways of programming or reprogramming non-volatile memory.

1.13 Input Devices

Keyboard

Enters text, numbers, commands and shortcuts.

Mouse

Pointing device used to select, drag, open and manipulate graphical objects.

Scanner

Converts physical documents or images into digital form.

Light pen

Pen-like pointing device historically used with suitable displays.

OMR

Optical Mark Recognition detects marked areas on forms, such as answer sheets.

OCR

Optical Character Recognition converts printed or image-based text into machine-readable characters.

BCR

Barcode Reader reads encoded patterns from barcodes.

MICR

Magnetic Ink Character Recognition reads special characters printed with magnetic ink, historically important in banking.

Touch screen

Detects touch input directly on a display.

Microphone

Converts sound into an electrical/digital signal for processing.

Digital camera

Captures photographs or video in digital form.
